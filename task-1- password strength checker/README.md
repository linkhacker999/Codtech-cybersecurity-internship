# Task 1: Password Strength Checker

This is a Python tool made for the **CodTech IT Solutions Cybersecurity Internship**. It checks how strong a password is and gives tips to make weak passwords safer.

## What It Does
* Checks if the password is at least 8 or 12 characters long.
* Checks for capital letters, small letters, numbers, and symbols.
* Gives a 0 score for common passwords like `123456` or `password`.

## How to Run
1. Run this command in the terminal:
   python passsword_checker.py
   2. Type a password and press Enter.
