# Task 2: Brute Force Simulator

This is a Python tool made for the **CodTech IT Solutions Cybersecurity Internship**. It shows how a brute-force attack guesses a password by trying every possible combination of letters and numbers.

## What It Does
* Tries combinations of small letters (`a-z`) and numbers (`0-9`).
* Counts the total number of attempts needed to guess the password.
* Measures the exact time taken in seconds to crack the password.

## How to Run
1. Run this command in the terminal:
   python brute_force_simulator.py
2. Enter a short test password (3 to 4 characters) and press Enter.
